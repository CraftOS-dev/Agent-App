# CraftBot actions

CraftBot is Agent-App-native and registers agent tools as **actions** via the `@action` decorator (from `agent_core`). This module defines 15 `@action`-decorated Python functions that build, operate, install and import Agent Apps by shelling the framework CLIs; importing it registers them in CraftBot's `ActionRegistry` under the `agent_app` action set.

- **Code:** [__init__.py](__init__.py) — `@action(name=, description=, input_schema=, output_schema=, action_sets=["agent_app"])` on `def fn(input_data: dict) -> dict`. The build and operate actions return `{ status, output, exit_code }`.
- **Marketplace and import**, under CraftBot's own names and arguments so its skills and agents keep working once it runs on this framework: `agent_app_marketplace_list()` (`agent-app catalogue`), `agent_app_marketplace_install(app_id, name?, description?, custom_fields?)` (`agent-app install <id>`, `custom_fields` as `--set`), `agent_app_inspect(source)` (`agent-app inspect --from`), and `agent_app_import(source, name?)` (`agent-app install --from`). They return CraftBot's shapes (`apps`, `project_id`, `project_path`, `message`) plus the CLI's own result. The CLI has no `--description`: an installed app's description comes from its catalogue entry, and `description` is accepted only so existing callers keep working. A source that is not an Agent App package comes back as an error naming its routes (convert or adopt, with the importer skill).
- **Tests:** `python harness-plugins/craftbot/test/test_actions.py` loads the module with a stand-in `agent_core` against the integration starter's fake CLIs, and checks that every action reads only the fields its schema declares and runs the binary that owns its verb.

Loaded inside CraftBot, which provides `agent_core`. Set `A2APP_CLI` (operate, default `a2app`) and `AGENT_APP_CLI` (build/evolve, default `agent-app`); a `…/cli.js` entry is run with Node. Install the CLIs with `npm i -g agent-app-framework`. Each action names the binary it runs, and no shell is used, so field values can't inject.
