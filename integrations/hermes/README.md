# hermes-agent integration

Directory plugin (`plugin.yaml` + `register(ctx)`) providing A2App tools wrapping the `a2app` CLI, a web-dashboard tab embedding app frontends (`plugin_api.py` route), `open_preview`/`drive_preview` on desktop, and cron wiring; capability-consent gated. Skills bundle is the messaging-surface fallback. Plan: [research/harness-hermes-deepseek.md](../../research/harness-hermes-deepseek.md).
