# openclaw integration

Plugin package (`openclaw.plugin.json` + `definePluginEntry`) registering: `agent_app_describe`/`agent_app_run` tools, `openclaw agent-app deploy/load/validate` CLI subcommands, a supervising background service, a reverse-proxy HTTP route, and per-app Control-UI tabs (sandboxed authenticated iframe). Ships the operator skill. Plan: [research/harness-openclaw.md](../../research/harness-openclaw.md).
